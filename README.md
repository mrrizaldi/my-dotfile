# my-dotfile

Personal setup for an HP Victus 15 (Intel iGPU + RTX 3050) on **Debian 13 trixie** running
**Hyprland 0.57 (Lua config)** on top of the [KooL / LinuxBeginnings Hyprland-Dots](https://github.com/LinuxBeginnings/Hyprland-Dots).

This repo only holds what differs from upstream. The dots themselves (`~/.config/hypr/scripts`,
`lua/`, `configs/system_*`, waybar themes, rofi, kitty, …) come from the pinned upstream in `upstream.env`.

The old ML4W/Arch setup lives in tag `ml4w-archive`.

## Layout

| Path | What |
|---|---|
| `home/<pkg>/` | GNU stow packages, linked file-by-file into `~` |
| `home/hypr` | `UserConfigs/*.lua`, `UserScripts/`, hypridle, hyprlock (matrix), waybar per-monitor config, `CLAUDE.md` + `docs/` |
| `home/quickshell` | Matrix lockscreen (`matrix-lock/`) |
| `home/shell` | zsh (oh-my-zsh + p10k), bash, profile |
| `home/term` | ghostty, fastfetch, cava, tmux (`tmux.conf.local`), zathura |
| `home/desktop` | mimeapps, Thunar actions, Chrome/Brave `.desktop` with `--ozone-platform=x11` |
| `home/systemd` | user units + the `~/.local/bin` scripts they run |
| `system/root/` | files copied into `/`: apt repos + keyrings, `nvidia-drm` early load, i915 VBT fix |
| `packages/` | `apt.txt`, manually installed `.deb`s |

## Fresh install

```sh
git clone git@github.com:mrrizaldi/my-dotfile.git ~/dev/my-dotfile && cd ~/dev/my-dotfile
./bootstrap.sh --system --packages --kool
cd ~/Debian-Hyprland-LB && ./install.sh          # interactive KooL installer
cd ~/dev/my-dotfile && ./bootstrap.sh --link
```

Then add the GRUB cmdline `--system` prints, and put API keys in `~/.config/shell/secrets.sh`
(`chmod 600`, never committed; `.zshrc`/`.bashrc` source it).

## Day to day

Files in `~` are symlinks into `home/`, so edits show up in `git diff` directly.
New file to track: move it into the matching `home/<pkg>/` path and run `./bootstrap.sh --link`.

User units are symlinks too, so systemd sees them as "linked": `systemctl --user disable <unit>`
deletes the link itself. Run `./bootstrap.sh --link` afterwards to put it back.

After a KooL upgrade (`copy.sh --upgrade` moves `~/.config/hypr` and `~/.config/quickshell` aside and
copies fresh ones, dropping the links): commit first, then `./bootstrap.sh --link` (repo version wins).

## Not in the repo

Secrets, `~/.gitconfig` and `gh` auth, nvim (own repo, cloned by `--link`), live wallpapers
(`~/.local/share/wallpaperengine`), hyprlock-matrix frames (regenerated by `gen.py`), project-specific
user units (`ai-stack`, `pa-serve`, `pa-latex-watch`, `remote-sign`: they live with their projects).
